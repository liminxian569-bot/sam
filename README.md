本專案採用 **C++ 物件導向程式設計 (OOP)** 架構開發。我們將系統功能拆解為資料管理、遊戲邏輯、流程控制三大模組，並透過多檔案編譯優化開發效率與維護性。

---

##  程式介紹
本程式是一款基於終端機命令列介面（CLI）開發的英文單字猜猜看遊戲。核心設計嚴格遵循物件導向設計原則：
1. **資料與邏輯分離**：全面取消硬編碼（Hardcoded）題庫，改由外部文字檔控管，程式在執行期（Runtime）才進行動態讀取。
2. **多檔案分離編譯**：將介面宣告（`.h`）與邏輯實作（`.cpp`）重構拆分，確保團隊多人協同開發時的程式碼整潔度與獨立性。
3. **物件組合應用 (Composition)**：核心控制模組內部動態組合了負責畫面反饋的寵物系統與記錄連勝成就的計分板系統，提高程式內聚力與物件重用性。

##  核心架構與分工資訊

###  專案目錄與人員負責架構
---

### 1. WordBank (外部題庫與動態資料管理) | 負責人：吳宸緯
* **角色定位：** 負責處理遊戲的核心資料持久化與難度抽題邏輯。
* **技術要點：**
    * **外部題庫整合**：實作 `ifstream` 檔案串流機制，將題庫移至外部檔案，達成資料與邏輯分離。
    * **自動化資料分流**：在讀取主題庫時，利用 `eng.length()` 判斷單字長度，自動將單字分類並生成 `easy.txt`、`normal.txt` 與 `hard.txt`。
    * **動態難度載入**：根據玩家選擇的難度參數，動態選取對應的環境檔案進行讀取，實現資料解耦並優化記憶體負載。
    * **隨機抽題與挖空**：結合隨機種子（Seed）確保每局獨特性，並開發自動挖空演算法，針對不同長度的單字執行遮蔽。

### 2. GameManager (遊戲邏輯與多媒體回饋) | 負責人：李旻憲
* **角色定位：** 擔任遊戲「裁判」，負責所有視覺輸出、血量監控與成就記錄。
* **技術要點：**
    * **Pet 子系統 (圖形化血量)**：獨立設計並實作 `Pet.h`，負責圖形化血量顯示，根據玩家當前血量與猜測對錯動態切換寵物的情緒狀態（HAPPY, SAD, ANGRY），強化視覺反饋。
    * **Scoreboard 子系統 (連勝紀錄)**：獨立設計並實作 `Scoreboard.h`，負責在記憶體中追蹤並累加玩家的連勝次數（Win Streak），提升遊戲挑戰性與成就感。
    * **比對機制與防呆**：即時比對玩家輸入與正確答案，更新題目顯示狀態；若字數不合則跳出防呆提醒而不扣血。
    * **視覺輸出**：負責繪製 ASCII 介面、顯示目前題目狀態與剩餘血量。

### 3. Main (程式主流程) | 負責人：李庭偉
* **角色定位：** 串聯各模組，並負責處理使用者的輸入例外與遊戲迴圈。
* **技術要點：**
    * **流程控制**：初始化 `WordBank`、`GameManager`、`Pet` 與 `Scoreboard` 物件，引導遊戲主迴圈.
    * **生命週期控管**：利用 `do-while` 迴圈處理遊戲重開機制，並在每局開始時重新實體化物件，確保暫存狀態被完全重置與釋放。

##  遊戲規則說明

### 1. 遊戲開始
系統會提示玩家選擇難度，並從對應題庫（簡單/中等/困難）隨機抽取單字，以隱藏模式顯示（例如：`c_mp_ter`），底線代表玩家需要猜測的字母。

### 2. 玩家操作
玩家每次需輸入完整單字或字母。為了保持畫面整潔，系統在每次輸入後會自動清空螢幕 (`system("cls")`) 以顯示最新遊戲狀態。

### 3. 判定邏輯
* **猜對了**：對應位置的底線轉為正確字母，寵物顯示正面情緒，維持血量。
* **猜錯了**：扣除 1 點血量（初始為 3 滴血），寵物顯示負面情緒，並提供精準的錯字格數反饋。
* **無效輸入**：若輸入重複字母、數字或與單字長度不符的字元，系統會給予廣告警告且不扣血。

### 4. 勝負判定
* **恭喜獲勝**：在血量歸零前補全單字，連勝紀錄（Scoreboard）加一。
* **遊戲失敗**：猜錯 3 次（血量歸零）即結束，連勝紀錄歸零並由系統公佈正確解答。

##  玩法說明
1. 啟動程式後，畫面會噴出難度選單，請輸入 `1` (簡單)、`2` (中等) 或 `3` (困難) 並按 Enter。
2. 進入遊玩畫面，觀察系統給出的【中文提示】與【英文單字】挖空進度。
3. 在輸入提示處打入你猜測的字母或單字答案。
4. 持續觀察畫面中 ASCII 寵物（Pet）的情緒表情、剩餘血量與目前連勝數。
5. 該局結束後，輸入 `Y` 可重新開啟新一局並繼承連勝紀錄，輸入 `N` 則結束並退出遊戲。

##  程式如何安裝與執行

### 1. 前置準備
* 請確保電腦作業系統已安裝支援 C++11 (含) 以上標準的編譯器環境（如 `GCC` / `MinGW-w64`）。

### 2. 多檔案分離編譯指令
打開終端機（PowerShell 或 CMD），切換至本專案所在的原始碼目錄夾，輸入以下編譯指令進行連結：
g++ main.cpp WordBank.cpp GameManager.cpp Pet.cpp Scoreboard.cpp -o main.exe
請確保題庫文字檔（easy.txt、normal.txt、hard.txt 以及原始 words.txt）與生成的 main.exe 位在同一個資料夾目錄下，接著輸入指令即可運行：
.\main.exe
